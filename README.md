# dad-birthday-45

Interactive birthday page for Mohammed (45) — created by Copilot.

This repository contains a single-page site (index.html) ready to publish with GitHub Pages.

How to publish

1. GitHub Pages should serve the `index.html` from the repository root on the `main` branch. If it doesn't appear after a minute, go to Settings → Pages and set Source to "Deploy from a branch" → `main` → `/ (root)` and save.
2. The published URL will be: https://kingmimi950-cyber.github.io/dad-birthday-45/

Customizations

- To change the name/date, edit the `birthISO` in the top of `index.html`.
- Replace the audio source if you want a different song.

Enjoy and happy birthday to your dad!
